# Project Skills

Skills in this directory are reusable procedures for Pi. Pi discovers each `SKILL.md` through the project resource configuration and loads the full instructions only when a task matches its description.

## Current Skills

- `file-analysis`: inspect a local file, identify likely problems, and report evidence.

## Add a Skill

Create `skills/<skill-name>/SKILL.md` and follow [the skill specification](../docs/SKILL_SPEC.md). Do not edit the orchestrator to register an ordinary skill.

Skills describe reasoning and workflow. Deterministic operations belong in Pi tools or tool extensions.
